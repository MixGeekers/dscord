# 登录与恢复

[应用说明](README.md) · [独立客户端部署](deploy/client/README.md)

## 保持登录

登录和注册默认勾选“记住此设备”。同一浏览器配置、同一客户端地址下，关闭标签页或彻底退出浏览器后，再打开可恢复原账号、会话位置与草稿。系统先核对归属服务、当前身份和房间权限，再允许发送。网络暂时不可用时保留登录和输入内容，恢复连接后继续使用。

自动恢复的有效期自这次登录起最多 **30 天**，这是本地的绝对上限，不会因为每次打开而无限延长，也不延长服务端 token 的期限。服务端提前撤销或禁用账号时仍会要求重新登录。中央会话和聊天会话分别有效：中央过期不会自动退出仍有效的聊天；需要 Bot 管理或 DSH 连接时，可从账号菜单重新登录。

公用设备可取消勾选，使用当前标签页的临时登录。关闭网页不是服务端退出操作；需要退出时使用“设置 → 账号 → 退出登录”。浏览器自己的会话还原可能保留临时标签页，这不等于选择了记住设备。

浏览器禁止或无法写入持久存储时会提示无法记住，并退化为当前标签页使用；两种存储均不可用时仍可在当前页面登录和发送，但重开不会恢复。

## 原会话、草稿与待确认消息

- 原位置、草稿、回复目标和已上传附件记录按完整账号身份、归属服务、服务器空间及房间保存；换号不加载另一账号的内容。
- 同一房间的多个标签页共享持久草稿，以最后保存的内容为准。较早消息的送达回执不会清除另一标签页新保存的不同草稿。
- 未完成上传的文件没有保存在浏览器草稿中，恢复后需重新选择。已上传附件是否仍可使用以服务端返回为准。
- 待确认发送保存原事务号。重新打开不会自动重发；用户重试时继续使用原事务号，保持服务端幂等。另一个标签页有不同消息等待确认时，先在原标签页处理，当前草稿保留。
- 原房间不再可访问时，回到有权使用的会话列表。重新连接不能恢复已经撤销的成员权限。

主动退出清除登录凭据；该账号的草稿和导航记录保留在本机，重新登录同一身份后可继续。清除站点数据会删除本地登录及草稿。浏览器之间、不同客户端地址之间以及普通浏览器与独立安装 PWA 之间，不保证共享存储。

## 多标签页与退出

同一客户端地址、同一浏览器配置使用一个记住的活动账号。登录另一账号会让其他已打开标签页跟随切换；退出也同步到其他标签页。临时登录的凭据不会交给其他标签页；发生切换时，旧标签页停止使用旧账号。

退出会请求聊天服务和中央结束对应会话。网络或通知清理失败时，仍清除本浏览器登录，并明确提示服务端未能确认全部结束。一个旧请求的迟到响应不会覆盖新账号，也不会撤销另一个标签页刚建立的新登录。

## 升级和部署

升级前仍打开且有效的旧会话可继续临时使用。再次成功登录并勾选记住设备后，才写入持久登录；已经随关闭标签页丢失的旧凭据无法恢复，升级后可能需要登录一次。

客户端继续支持纯静态托管，认证请求仍固定发给已配置的 Core 和它接入的中央，采用 Bearer 且不携带环境 Cookie。不会从 URL 参数替换认证目标。归属 Core、Matrix 或中央绑定变化时，不把原凭据发送给新目标。

记住设备将会话 token 保存于客户端站点的浏览器存储，不保存密码；站点脚本可以读取这些 token。它沿用现有客户端认证方式，没有引入 HttpOnly Cookie、BFF、中央 SSO 或 Passkey。管理员后台的登录期限和存储方式没有随普通聊天改变。

中央默认登录会话采用 30 天未使用过期；网页的普通 Core 轮询不代表调用中央会话。聊天会话有效期由部署的 Matrix/Synapse 配置决定，不能把浏览器的本地期限当成服务端统一撤销期限。

## 验证范围

模块回归覆盖本地期限、绑定隔离、临时模式、旧标签页失效、迟到失败、受限存储和待确认事务号。生产构建的 Chromium 测试使用分开的静态客户端、Core 和中央 HTTP origin，以及合成账号/API，验证完整浏览器进程重启、原房间和草稿恢复、多标签页退出换号、断网重连、服务端撤销及存储禁用。

这些浏览器夹具不等于真实 Matrix 或手机实机验收。Safari/iPhone 已安装 PWA 的存储回收和冷启动行为需另留实机证据；清除数据、无痕浏览和系统回收仍可能使本地记录不可恢复。
